# TEITELBAUM — THE SATMAR LEGACY
## A Living Digital Encyclopedia of Satmar Hasidism (RU / EN / HE)

Независимый многоязычный историко-культурный портал и генеалогический архив, посвящённый Сатмарскому хасидизму, династии Тейтельбаум (с 1759 г.), ребе Йоэлю Тейтельбауму (1887–1979), последующим поколениям ребе и современной жизни общин по всему миру.

### 1. Архитектура проекта
- **Автономная интерактивная сборка (`public/index.html` / Canvas Web App)**: работает мгновенно в любом современном браузере без необходимости настройки БД.
- **Next.js 14 + React + TypeScript + Tailwind CSS (`src/`)**: модульная архитектура с полным отделением структурированных исторических данных от UI-компонентов, поддержкой SEO, Open Graph, `sitemap.ts`, `robots.ts` и поддержкой RTL для иврита (`dir="rtl"`).

### 2. Инструкция по локальному запуску (Next.js)
```bash
# 1. Установка зависимостей
npm install

# 2. Запуск сервера разработки
npm run dev

# 3. Сборка для продакшена
npm run build && npm run start
```
Откройте `http://localhost:3000` в браузере. (По требованию ТЗ проект не публикуется на внешнем домене и не изменяет настройки DNS без отдельного подтверждения).
