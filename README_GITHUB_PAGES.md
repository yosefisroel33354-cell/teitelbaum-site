# TEITELBAUM — THE SATMAR LEGACY (GitHub Pages Ready Package)

В этом архиве файл `index.html` уже содержит ВСЕ 6 исторических иллюстраций и музейных картин, вшитых прямо внутрь самого кода `index.html` (в формате Base64), поэтому картинки отображаются мгновенно и никогда не теряются при загрузке на GitHub Pages!

## Как загрузить на GitHub Pages:
1. Загрузите `index.html` и `404.html` прямо в корень вашего репозитория `teitelbaum-site`.
2. Все картинки уже находятся внутри файла `index.html` (размер файла ~2.1 МБ).
